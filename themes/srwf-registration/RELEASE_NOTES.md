# SRWF Registration Release Notes

Release-Version: 0.1.19

SRWF Registration 0.1.19 is the first minimal production release of the SRWF Registration presentation theme for Gravity Theme Builder.

- Gravity Forms remains authoritative for form behavior, validation, submission, semantics, conditional behavior, and persistence.
- Per-form GTB Registration presentation is isolated from Gravity Flow Entry Detail.
- Full Width page/content layout remains host-owned.
- Responsive mobile presentation retains the canonical 16px GTB gutter.
- Desktop presentation uses the approved 904px outer / 840px content shell at `>=960px`.
- All authentic SRWF Radio fields use responsive card presentation.
- GP Advanced Select / Tom Select presentation is integrated without behavior takeover.
- GP File Upload Pro initial presentation family is integrated without lifecycle takeover.
- Owner minimum-release manual checks passed for 320px reflow, representative desktop presentation, authentic Gravity Forms validation, the primary keyboard-focus path, GP Advanced Select search/selection, real GP File Upload Pro upload workflow, and successful end-to-end form submission.

This is a minimal release, not a claim that every extended qualification state has been exhaustively exercised. Broader responsive/accessibility/add-on-state qualification continues after release, including unexercised widths, 200% text resize, text spacing, rare GPAS states, GPFUP crop/re-crop/delete states, and complete accessibility qualification.

No license has been selected. License selection remains a separate Owner decision.
